# Multimodal-modelling-of-bayesian-neural-network-for-one-to-many-mapping-in-image-enhancement
Multimodal modelling of bayesian neural network for one to many mapping in image enhancement
1) To retrain the model, install the dependencies, download the dataset, change the input and output directories in the train.py and run the code.
2) To test the results, install the dependencies, download the dataset, change the input, output and checkpoint directories in the test.py and run the code. The results will be reproduced.
